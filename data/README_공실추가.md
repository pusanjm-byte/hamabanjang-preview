# 공실 추가하는 방법 (vacancies.html)

> 이 페이지는 메뉴에 없고 검색에도 나오지 않게 해 두었습니다. 공개 여부와 법 기준(공인중개사가 아닌 사람의 매물 광고 제한 여부)은 아직 확인 전입니다. 공개하기 전에 꼭 확인합니다.

## 1. 순서
1. `data/vacancies.js`를 메모장(또는 VS Code)으로 엽니다. 고치기 전에 파일을 복사해 백업해 둡니다.
2. `window.VACANCIES = [];`의 대괄호 `[ ]` 안에 아래 예시 묶음을 붙여 넣고 값을 바꿉니다. 방이 둘 이상이면 묶음 사이에 쉼표(`,`)를 찍습니다.
3. 저장한 뒤 `vacancies.html`을 더블클릭해 카드가 나오는지 봅니다.

## 2. 예시 묶음
```js
{
  id: "v-001",                          // 영어 소문자·숫자·빼기(-)만, 겹치지 않게
  건물유형: "원룸·다가구",               // 또는 "오피스텔·도시형 생활주택"
  구: "동래구", 동: "온천동",
  구조: "원룸", 면적: "[ ]", 층: "[ ]층",
  보증금: "[ ]", 월세: "[ ]", 관리비: "[ ]",
  입주가능일: "[ ]",
  옵션: ["에어컨", "냉장고"],
  사진목록: [{ 이름: "방 사진", 설명: "", 파일: "" }],  // 사진은 assets/img/vacancies/ 에 넣고 경로를 적습니다
  한달살기가능: false,                  // 30일 이상 계약이 되면 true
  협력중개사무소: { 상호: "", 대표: "", 등록번호: "", 주소: "", 전화: "" },
  게시일: "2026-00-00"
}
```

## 3. 꼭 지킬 것
- **협력중개사무소 칸은 반드시 채웁니다.** 상호·대표·등록번호·전화 중 하나라도 비어 있으면 그 방은 화면에 아예 나오지 않습니다(일부러 그렇게 만들었습니다).
- 카드에는 "문의: 상호 · 대표 · 등록번호 · 전화"가 자동으로 붙습니다. 하마반장 연락처는 넣지 않습니다.
- **한 달 살기**는 30일 이상 계약할 수 있는 방에만 `true`로 둡니다. 30일 미만 단기(몇 주 단위) 표시는 쓰지 않습니다.
- 금액·면적·입주일은 실제 자료만 씁니다. 모르면 `"[ ]"`로 둡니다(회색 칸으로 보입니다).
- 세입자 이름·연락처, 호실 번호처럼 사람을 알아볼 수 있는 정보는 적지 않습니다.
- 계약이 끝난 방은 묶음을 지웁니다.

## 4. 잘못 고쳤을 때
- 화면에 "지금 안내할 공실이 없습니다"만 나오면, 협력중개사무소 칸이 비었거나 쉼표·따옴표·괄호가 빠졌을 가능성이 큽니다. 백업 파일로 되돌린 뒤 다시 고칩니다.

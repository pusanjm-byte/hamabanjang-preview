# 관리 사례 추가하는 방법

사례는 `data/cases.js` 파일 하나만 고치면 늘어납니다. 페이지 HTML은 건드리지 않습니다.
사례를 넣으면 **관리 사례 목록, 거르기 버튼, 사례 상세, 관리 방식 페이지의 '이 유형의 관리 사례', 홈의 '관리 사례'**가 저절로 바뀝니다.

## 1. 순서
1. `data/cases.js`를 메모장(또는 VS Code)으로 엽니다. 고치기 전에 파일을 복사해 백업해 둡니다.
2. 맨 아래 `];` 바로 위, 마지막 사례의 `}` 뒤에 쉼표 `,`를 찍습니다.
3. 첫 사례(`id: "oncheon-15"`) 묶음을 통째로 복사해 붙여 넣고, 내용을 새 건물에 맞게 바꿉니다.
4. 저장한 뒤 `cases.html`을 더블클릭해 목록에 나오는지, 카드를 눌러 상세가 열리는지 봅니다.

## 2. 꼭 지킬 것
- **id**: 영어 소문자·숫자·빼기(-)만 씁니다. 다른 사례와 겹치면 안 됩니다. 예: `"case-02"`
- **공개동의**: 건물주가 이름·주소·사진 공개에 동의했으면 `true`, 아니면 `false`.
  - `false`이면 화면에는 제목(예: "온천동 15세대 원룸")과 구·동만 나옵니다.
  - **이 파일은 홈페이지를 보는 누구나 내려받을 수 있습니다.** 동의 전에는 `건물이름`, `주소`를 빈칸(`""`)으로 두고, 번지·도로명·주변 가게나 학교 이름도 어디에도 적지 않습니다.
- **건물유형**: `"원룸·다가구"` 또는 `"오피스텔·도시형 생활주택"` 둘 중 하나를 글자 그대로 씁니다(관리 방식 페이지와 연결됩니다).
- **구**: `"동래구"`처럼 '구'까지 씁니다. 거르기 버튼이 이 글자로 만들어집니다.
- **해결한일**: 실제로 한 일만 고릅니다. `"공실"`, `"민원"`, `"수리"`, `"퇴실 정산"`, `"점검"` 중에서 씁니다.
- **받지 못한 자료**는 `"[ ]"` 또는 `"[확인 중]"`처럼 대괄호로 씁니다. 화면에 회색 칸으로 표시됩니다.
- 숫자·후기·기간·성과는 실제 자료가 있을 때만 씁니다. 지어내지 않습니다.
- **메모**는 화면에 나오지 않지만 파일이 공개되므로 비밀 내용은 쓰지 않습니다.

## 3. 칸 설명
| 칸 | 쓰는 것 | 예 |
|---|---|---|
| 제목 | 동네 + 세대수 + 건물 종류 | `"온천동 15세대 풀옵션 원룸"` |
| 동 | 동 이름 | `"온천동"` |
| 세대수 | 숫자 | `15` |
| 요약 | 한두 문장 | |
| 요약칩 | 첫 화면 작은 표시 3개 정도 | `["15세대", "풀옵션"]` |
| 개요 | `["항목", "내용"]` 묶음 | `["승강기", "있음"]` |
| 옵션 | `["옵션 이름", "포함/[ ]"]` | `["에어컨", "포함"]` |
| 사진목록 | `{ 이름, 설명, 파일 }`. 파일이 비어 있으면 회색 사진 자리가 나옵니다. 사진은 `assets/img/cases/` 에 넣고 `"assets/img/cases/파일이름.jpg"`로 적습니다. 첫 번째 사진이 목록 카드에 나옵니다. | |
| 임대현황표.행 | 호실별 `{ 호실, 구조, 보증금, 월세, 관리비, 만기, 상태 }`. 비워 두면 '예시 화면' 카드가 나옵니다. | |
| 입지 | 약도 그림 경로, 지하철 거리, 주변 설명, 소식. 동의 전에는 정확한 지도 대신 대략 약도만 씁니다. | |
| 업체흐름 | `{ 단계, 맡는곳: [...], 하마반장: true }`. 하마반장이 맡는 단계에만 `하마반장: true` | |
| 민원 | `["민원", "보통 원인", "연결 업체"]` | |
| 점검 | `["항목", "주기", "업체"]` | |
| 공과금 | `["항목", "월 금액"]` | |
| 시설물 | 이름 목록 | |

## 4. 잘못 고쳤을 때
- 화면이 비거나 "사례를 찾을 수 없습니다"가 나오면 쉼표·따옴표·괄호가 빠졌을 가능성이 큽니다. 백업 파일로 되돌린 뒤 다시 고칩니다.
- 사이트의 공통 머리·바닥글은 `_src/build.mjs`로 만듭니다. 사례 추가에는 필요 없습니다.
